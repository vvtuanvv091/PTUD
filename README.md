# PTUD - Phát triển Ứng dụng Web

Repository lưu trữ toàn bộ bài tập và đồ án học phần Phát triển Ứng dụng Web.

---

## Cấu trúc thư mục

- `BAIKIEMTRA_05_10/`: Bài kiểm tra ngày 05/10.
- `BAITAPCANHAN_FINAL/`: Bài tập cá nhân hoàn thiện.
- `bookstore-mern/`: Ứng dụng Bookstore xây dựng bằng MERN Stack.
- `mini_project/`: Bài tập mini project.
- `Xây dựng Hệ thống Lớp học Trực tuyến (Online Classroom)/`: **Đồ án cuối kỳ môn học** (Hệ thống lớp học trực tuyến EduClass - MERN Stack).

---

## Chi tiết đồ án cuối kỳ: Xây dựng Hệ thống Lớp học Trực tuyến (Online Classroom)

* **Công nghệ:** MongoDB, Express.js, React.js (Bootstrap 5), Node.js (MERN Stack).
* **3 Vai trò chính:** Quản trị viên (Admin), Giảng viên (Teacher), Sinh viên (Student).
* **Hướng dẫn cài đặt & khởi chạy:** Xem chi tiết tại tệp [`README.md` trong thư mục Đồ án](./Xây%20dựng%20Hệ%20thống%20Lớp%20học%20Trực%20tuyến%20(Online%20Classroom)/README.md).
